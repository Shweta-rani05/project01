 🛒 Amazon Clone (HTML & CSS)

A responsive **Amazon homepage clone** built using **pure HTML and CSS**, focusing on layout accuracy, clean UI, and interactive design elements.  
This project helped me strengthen my **frontend fundamentals** and understand real-world website structure.

 📌 Features

- ✅ Responsive **Header** with logo, search bar, and navigation
- ✅ Fully structured **Footer** similar to Amazon
- ✅ Interactive **UI elements** (hover effects, buttons, links)
- ✅ Product sections with clean layout
- ✅ Modern styling using CSS
- ✅ Pixel-inspired design close to Amazon’s UI

 🛠️ Tech Stack

  - HTML5
  - CSS3
  - Flexbox
  - Grid
  - Hover effects
  - Responsive layout
